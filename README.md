# 🤖 سلف‌بات تلگرام

سلف‌بات فارسی قدرتمند تلگرام با Telethon — مدیریت اکانت، اوتوکلیکر، زمان‌بندی پیام، آنتی‌دیلیت و کلی قابلیت دیگه.

> ⚠️ **توجه:** سلف‌بات‌ها خلاف قوانین تلگرام هستن و ممکنه باعث محدودیت اکانت بشن. با مسئولیت خودتون استفاده کنید.

---

## ✨ قابلیت‌ها

### 🖱️ اوتوکلیکر (تسک)
| دستور | توضیح |
|-------|-------|
| `.تسک اضافه نام\|کلمه کلیدی\|متن دکمه\|تاخیر` | ساخت تسک جدید |
| `.تسک لیست` | نمایش تسک‌ها |
| `.تسک حذف نام` | حذف تسک |
| `.روشن نام` | فعال‌سازی اوتوکلیکر |
| `.خاموش` | غیرفعال‌سازی |

- کلمه کلیدی توی **متن پیام یا متن دکمه‌ها** جستجو می‌شه
- تطابق دکمه **هوشمنده** (ایموجی اول دکمه نادیده گرفته می‌شه)
- وضعیت اوتوکلیکر بعد از ری‌استارت **حفظ می‌شه**

### ⏰ زمان‌بندی
| دستور | توضیح |
|-------|-------|
| `.زمانبندی اضافه 10m متن` | ارسال یک‌باره بعد از ۱۰ دقیقه |
| `.زمانبندی اضافه 14:30 متن` | ارسال در ساعت مشخص (به وقت تهران) |
| `.زمانبندی تکرار 5m متن` | تکرار هر ۵ دقیقه |
| `.زمانبندی لیست` | نمایش زمان‌بندی‌ها |
| `.زمانبندی حذف آیدی` | حذف زمان‌بندی |

### 🛡️ آنتی‌دیلیت و آنتی‌ادیت
| دستور | توضیح |
|-------|-------|
| `.آنتی دیلیت روشن` / `.آنتی دیلیت خاموش` | ذخیره پیام‌های حذف‌شده |
| `.آنتی ادیت روشن` / `.آنتی ادیت خاموش` | نمایش تغییرات پیام‌های ویرایش‌شده |

### 🎨 فونت و پروفایل
| دستور | توضیح |
|-------|-------|
| `.فونت اسم رندم متن` | اسم با فونت رندم (چرخش خودکار) |
| `.فونت اسم خاموش` | توقف چرخش فونت اسم |
| `.فونت بیو رندم متن` | بیو با فونت رندم |
| `.بیو رندم` | چرخش خودکار بیو هر ۱۰ دقیقه |
| `.بیو رندم خاموش` | توقف چرخش بیو |
| `.ساعت` | ساعت فعلی با ایموجی مناسب |
| `.اسم متن` | تغییر اسم |
| `.بیو متن` | تغییر بیو |

### 🔧 کاربردی
| دستور | توضیح |
|-------|-------|
| `.پینگ` | سرعت پاسخ |
| `.آمار` | آمار پیام‌ها |
| `.ایدی` | آیدی چت/کاربر (روی پیام ریپلای کنید) |

| `.افک روشن متن` | پاسخ خودکار در غیاب |
| `.افک خاموش` | غیرفعال‌سازی AFK |

## 🚀 نصب و راه‌اندازی

### ۱. پیش‌نیازها
```bash
pip install -r requirements.txt
```

### ۲. دریافت API
از [my.telegram.org](https://my.telegram.org) مقدار `API_ID` و `API_HASH` رو بگیرید.

### ۳. تنظیمات
فایل `.env.example` رو به `.env` کپی کنید و مقادیر رو پر کنید:
```bash
cp .env.example .env
```

```env
API_ID=12345678
API_HASH=your_api_hash_here
SELFBOT_SESSION=mine_session
```

### ۴. اجرا
```bash
python selfbot.py
```
بار اول شماره تلفن و کد تأیید رو وارد کنید. سشن ذخیره می‌شه و دفعات بعد نیازی نیست.
