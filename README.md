# 🤖 سلف‌بات تلگرام v2

سلف‌بات فارسی تلگرام با کلی قابلیت — از آنتی‌دیلیت و آنتی‌ادیت گرفته تا فونت‌های فانتزی، بیو رندم، اتوکلیکر و زمان‌بندی پیام.

> ⚠️ **توجه:** سلف‌بات با اکانت شخصی شما لاگین می‌کنه. مسئولیت استفاده با خودتونه و ممکنه خلاف قوانین تلگرام باشه.

---

## ✨ قابلیت‌ها

### 🛡 محافظت
| دستور | توضیح |
|---|---|
| `.آنتی دیلیت روشن/خاموش` | وقتی کسی پیامش رو پاک کنه، سلف دوباره می‌فرسته |
| `.آنتی ادیت روشن/خاموش` | وقتی کسی پیامش رو ویرایش کنه، نسخه‌ی قبلی نمایش داده می‌شه |
| `.معاف [ایدی]` | این چت رو از آنتی‌دیلیت/آنتی‌ادیت معاف کن |
| `.شامل [ایدی]` | معافیت رو بردار |

### 👤 پروفایل
| دستور | توضیح |
|---|---|
| `.اسم [نام]` | تغییر نام پروفایل |
| `.بیو [متن]` | تغییر بیو |
| `.بیو رندم` | یه جمله‌ی شانسی از ۲۶ جمله‌ی فارسی به‌عنوان بیو |
| `.فونت اسم [استایل] [متن]` | تغییر نام با فونت فانتزی |
| `.فونت بیو [استایل] [متن]` | تغییر بیو با فونت فانتزی |
| `.فونت [استایل] [متن]` | فقط پیش‌نمایش متن با فونت |
| `.فونت لیست` | دیدن همه‌ی استایل‌های فونت |
| `.تایم بیو روشن/خاموش` | نمایش ساعت زنده توی بیو |
| `.سیو` | ذخیره‌ی مدیا (ریپلای روی پیام مدیادار) |

**استایل‌های فونت:** `bold`، `italic`، `mono`، `double`، `fraktur`، `circle`، `full`، `kashida`، `overline` — یا `رندم` برای انتخاب شانسی!
مثال: `.فونت اسم bold علی` → 𝐀𝐥𝐢

### 🎲 سرگرمی
`.شیر یا خط` | `.تاس` | `.عشق [نام]` | `.سنگ کاغذ قیچی [سنگ/کاغذ/قیچی]`

| دستور | توضیح |
|---|---|

| `.حذف [تعداد]` | حذف چند پیام آخر خودت |
| `.پاکسازی [تعداد]` | پاکسازی پیام‌ها |

### 🔧 ابزار
| دستور | توضیح |
|---|---|
| `.ترجمه` | ترجمه‌ی پیام (ریپلای روی پیام) |
| `.حساب [عبارت]` | ماشین‌حساب امن |
| `.ایدی [یوزر]` | گرفتن ایدی کاربر |
| `.قیمت ارز` / `.قیمت طلا` | قیمت لحظه‌ای |
| `.اذان [شهر]` | اوقات شرعی |
| `.ساعت` | ساعت فعلی با ایموجی |

### 🤖 اتوکلیکر
| دستور | توضیح |
|---|---|
| `.تسک اضافه نام|کلمه|دکمه|تاخیر` | ساخت تسک خودکار |

### ⏰ زمان‌بندی و AFK

## 🚀 نصب و اجرا

### پیش‌نیاز
- Python 3.10 یا بالاتر
- اکانت تلگرام

### قدم ۱ — گرفتن API_ID و API_HASH
1. برو به [my.telegram.org](https://my.telegram.org)
2. با شماره‌ت لاگین کن
3. بخش **API development tools** → یه اپ بساز
4. `api_id` و `api_hash` رو کپی کن

### قدم ۲ — نصب
```bash
git clone https://github.com/armadgarsone2/selfbot.git
cd selfbot
pip install -r requirements.txt
cp .env.example .env
```

### قدم ۳ — تنظیم
فایل `.env` رو باز کن و پر کن:
```env
API_ID=12345678
API_HASH=your_api_hash_here
```

### قدم ۴ — اجرا
```bash
python selfbot.py
```
بار اول شماره‌ت رو می‌خواد و یه کد تأیید به تلگرامت می‌فرسته. بعدش سشن ذخیره می‌شه و دیگه لازم نیست.

### اجرای دائمی (سرور لینوکس)
```bash
nohup python3 selfbot.py > selfbot.log 2>&1 &
```

## 🔒 امنیت

- **هیچ‌وقت** فایل `.env` و فایل‌های `.session` رو با کسی به اشتراک نذار یا توی گیت کامیت نکن (توی `.gitignore` هستن)
- اگه `API_HASH` لو رفت، از [my.telegram.org](https://my.telegram.org) revokeش کن و یه جفت جدید بگیر
- سلف‌بات فقط یه نمونه اجرا می‌شه (قفل تک‌نمونه داره)
